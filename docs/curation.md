# First collection: selection and evidence

Selected September 22, 2026. All work is labelled as unreviewed; no journal
acceptance, DOI, or independent evaluation panel is claimed.

- **E010 learned KV policy pilot:** completed locally, 792 primary rows across
  33 conditions on 24 shared task units, followed by an explicitly post-primary
  120-row diagnostic. Four storage/accounting tests and model parity/causality
  gates passed. The exposure hypothesis has no consistent gain. The endpoint
  confounds instruction/format retention with retrieval; the report preserves it.
- **E009 voice ablation:** six final adapter hashes, 384-step completion records,
  matched initialization, data/review/code hashes, and cross-run environment
  checks passed again. Personal balance snapshots were removed from the public
  edition. Scientific outcomes and raw responses remain visible. The effect
  overlaps a matched replacement control; there is no subjective-experience claim.
- **E006 heart walls:** the fresh 550-session analysis exactly reproduces the
  committed summary. Its unit is an installed agent session, not an isolated model.
- **Learn2Design fixed-rate diagnostic:** fresh independent NPZ/JSON replay
  verifies all four runs and the mean paired difference -1.6138125667514436.
  This is two topologies at one seed, not a competitive leaderboard claim.
- **GHZ closure:** both exact symbolic and independently implemented numerical
  checkers pass through the documented finite orders. The written induction is
  the theorem. The public edition explicitly requires nonnegative loss in
  Corollary D and limits the proof-route conclusion to closed tensor-only
  separators. The global Krenn–Gu conjecture remains unresolved.
- **Relational layer geometry:** analysis regenerated and manuscript validation
  passed. The original PDF is preserved. The transfer gain is limited by a
  synthetic task and capability ceiling, not a general model-compression result.

`content/provenance.json` records imported manuscript hashes and edition notes.
The LLM evidence release is a scoped public branch; unrelated development
experiments were not included. Original project checkouts and local archives
remain preserved.
